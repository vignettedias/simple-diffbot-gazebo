# Simple DiffBot Gazebo

A ROS 2 and Gazebo project implementing a differential-drive mobile robot.

## Project Goals

- Create a URDF-based robot model
- Simulate the robot in Gazebo
- Implement differential drive control
- Add sensors (LiDAR, Camera, IMU)
- Enable SLAM and Navigation
